# Dave Keller

Sales and marketing lead who builds the commercial systems behind the business.

Since March 2026 I've designed and run a full internal platform, built with
Claude Code, that replaced a multi-tool SaaS stack (CRM, helpdesk, forms,
marketing automation and reporting):

- **Stack:** TypeScript, Next.js, PostgreSQL, Redis/BullMQ, AWS
- **Scale:** 3,400+ commits, ~440 database tables, 55 scheduled jobs, 160+ API routes
- **Integrations:** Stripe, GoCardless, WooCommerce, Google Ads, Meta, Microsoft Ads,
  GA4, Amazon SES, Twilio, Companies House
- **AI:** Claude API for sales and support reply drafts, inbox routing, and a
  B2B enrichment pipeline that uses multi-read agreement checks and evals
- **Reliability:** resumable syncs, webhook retry handling, CI with secret
  scanning, immutable audit trail, automated health checks and alerts

The code is private, but I'm happy to walk through how it works.
